## Checklist Final

<Steps>
  <Step title="Variáveis de ambiente">
    Na Vercel adicione:
    - PAYLOAD_SECRET
    - DATABASE_URI
    - NEXT_PUBLIC_SERVER_URL
  </Step>
  <Step title="Build Command">
    `npm run build` - o Payload precisa gerar os types no build
  </Step>
  <Step title="Teste em produção">
    Acesse seu-dominio.vercel.app/admin e crie a primeira Page
  </Step>
</Steps>

## Comandos

```bash
npm run generate:types
npm run build
vercel --prod
```
