Bem-vindo à documentação completa para construir um **portfólio profissional, editável e performático** usando **Payload CMS 3.0 + Next.js 15 + TypeScript**.

Essa documentação nasceu de problemas reais: erros de importação de Blocks, CSS que não aplicava, e falta de conteúdo em português sobre Payload.

## O que vamos construir

Um site de portfólio completo com 7 blocos editáveis pelo cliente no painel do Payload.

## Por que Payload + Next.js?

<Tabs defaultValue="payload">
  <TabsList>
    <TabsTrigger value="payload">Payload vs Strapi/WordPress</TabsTrigger>
    <TabsTrigger value="next">Por que Next App Router</TabsTrigger>
  </TabsList>
  <TabsContent value="payload">
    - **Tudo é TypeScript:** Collections e Blocks geram tipos automaticamente
    - **Sem lock-in:** Você controla o banco
    - **Blocks nativos:** Perfeito para page builder como `SobreBlock`, `ServicosBlock`
  </TabsContent>
  <TabsContent value="next">
    - **RSC + Server Actions:** Busca dados do Payload direto no server
    - **CSS Module suportado:** Solução para `import './styles.css'` que não funciona
    - **Image Optimization + SEO:** `generateMetadata` puxando do Payload
  </TabsContent>
</Tabs>

## Stack final

| Tecnologia | Versão | Uso |
| :--- | :--- | :--- |
| Next.js | 16.3.5 | Framework + Turbopack |
| Payload CMS | 3.x | CMS Headless |
| TypeScript | 5.x | Tipagem total |
| Tailwind CSS | 4.x | Estilização |
| MongoDB / Postgres | - | Banco |
