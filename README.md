# </Seiti> Docs

Documentação do portfólio Seiti, construída com **Next.js**, **React**, **Tailwind CSS** e **TypeScript**.

> **Demo:** https://doc.seiti.com.br

## Instalação

```bash
git clone https://github.com/renatotgakishi/seiti-docs.git
cd seiti-docs
pnpm install
pnpm generate-content-json
pnpm run dev
```

Acesse [http://localhost:3000](http://localhost:3000)

## Produção

```bash
pnpm run build
pnpm run start
```
